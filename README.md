# Multi-Step Redirect

This project is a simple HTML-based demo to learn how link redirection works using buttons, timers, and multiple HTML pages.

## 🚀 What It Does

- Starts on a basic landing page with a button.
- Redirects to a second and third page with a 15-second countdown.
- Displays a button after the countdown instead of auto-redirecting.
- When clicked, the button manually redirects to the next step.


## 🧠 Learning Goals

- Understand how to use JavaScript to control redirection.
- Learn how to create timers and dynamically update the page.
- Practice basic HTML/CSS and DOM manipulation.

## 🛠️ Technologies Used

- HTML5
- JavaScript
- CSS (inline for simplicity)

## 💡 How to Use

1. Open `index.html` in your browser.
2. Click the **Click to continue** button.
3. Follow the countdown and click the buttons as they appear.
4. Observe how redirection is controlled step by step.
